# Sate Kajang Hj. Samuri — online ordering (design prototype)

A proposed ordering website for Sate Kajang Hj. Samuri. Plain HTML, CSS and JavaScript — no build step, no dependencies.

**Prototype only.** No orders are sent and no payments are processed.

## View it

- **Online:** in this repo go to *Settings → Pages*, set *Source* to "Deploy from a branch", choose `main` and `/ (root)`, then save. The site appears at `https://<username>.github.io/<repo-name>/` after a minute or two.
- **Locally:** open `index.html` in a browser.

## What's inside

| File | Purpose |
|---|---|
| `index.html` | Page structure |
| `styles.css` | All styling, including the mobile layout |
| `data.js` | Menu, prices (inclusive of 6% SST) and branch details |
| `app.js` | Sate builder, cart, checkout and branch hours |
| `assets/` | Skewer cut-outs, grill and side-dish photos |

Most menu photos load from the current satekajang.com.my media library.
